# Раскрываемое дерево и отдельный корень анализа — после MVP

Статус: отложенный вариант, сохранён по решению пользователя 2026-10-30. Не входит в первую версию; этот документ не является заданием на реализацию.

Актуальные требования: [спецификация MVP](../specs/2026-10-30-disk-cleaner-design.md) и [план MVP](../plans/2026-10-30-disk-cleaner-mvp.md). Первая версия показывает список текущего каталога, который одновременно является корнем анализа.

## Для чего возвращаться к дереву

Дерево полезно, когда пользователь хочет одновременно видеть несколько ветвей, осматривать вложенные папки и задавать исключения, сохраняя текущий корень анализа. Например, перед анализом `~` раскрыть `Library` и `Developer`, найти вложенные каталоги и добавить маски их имён без перехода в отдельный контекст анализа.

## Сохранённый вариант взаимодействия

1. При запуске отображается дерево от `~` без размеров. Скрытые элементы доступны; содержимое папки читается только при её раскрытии.
2. Несколько ветвей могут оставаться раскрытыми одновременно. Раскрытие и сворачивание меняют представление, но не корень анализа, исключения или снимок размеров.
3. Выделенная строка и корень анализа — разные понятия. Интерфейс явно показывает путь корня, к которому относятся `s`, исключения и выбор на удаление.
4. Отдельная команда `R` делает выделенный каталог новым корнем анализа и показывает дерево от него. Ввод пути через `r` позволяет выбрать корень напрямую, включая внешний том.
5. Только команда `s` запускает анализ. Как в MVP, размеры измеряются для непосредственных элементов корня. Раскрытые потомки не получают отдельные размеры автоматически: для их анализа нужно сменить корень.
6. Отметка для удаления разрешена только для непосредственных элементов проанализированного корня. Возможность видеть более глубокую строку не делает её доступной для выбора на удаление.
7. Команда исключения на вложенной папке создаёт маску её имени для всего текущего корня. Перед применением интерфейс объясняет, что совпадения в других ветвях тоже будут исключены. Маски сохраняются отдельно для корня.
8. Смена корня сбрасывает снимок и отметки; загружаются исключения нового корня. Само раскрытие папки этого не делает. Изменение исключений сбрасывает снимок и отметки согласно общим правилам безопасности.

Предварительные клавиши, требующие проверки удобства перед реализацией:

| Действие | Предлагаемая клавиша |
| --- | --- |
| Перемещение по видимым строкам | `↑/↓` |
| Раскрыть папку | `→` или `Enter` |
| Свернуть папку; если она уже свёрнута — выделить родителя | `←` |
| Сделать выделенную папку корнем анализа | `R` |
| Выбрать корень вводом пути | `r` |
| Запустить анализ текущего корня | `s` |
| Добавить или убрать маску имени папки | `x` |

## Отличие от первой версии

| Свойство | MVP: список текущего каталога | Будущее дерево |
| --- | --- | --- |
| Одновременно видимые уровни | Один | Несколько раскрытых ветвей |
| Открытие папки | Меняет текущий каталог и корень | Раскрывает ветвь без смены корня |
| Выбор корня | Совпадает с переходом в каталог | Отдельная команда |
| Исключение вложенного имени до анализа родителя | Ввод маски вручную | Выбор вложенной папки в дереве или ввод маски |
| Состояние интерфейса | Текущий путь, список, курсор, снимок | Дополнительно раскрытые ветви и курсор среди нескольких уровней |

## Что сохраняется из MVP

- Английский интерфейс, ручной запуск анализа и возможность отмены.
- Сохранение исключений между запусками для каждого корня.
- Отдельный необязательный тестовый прогон с перечислением вложенных путей; обязательное подтверждение реального действия.
- Фиксация объекта при отметке и повторная проверка перед действием; защита путей, идентичностей и исключённых потомков.
- Корзина и окончательное удаление, отчёт по каждому пути, сброс устаревших размеров и отметок после попытки очистки.
- Отсутствие автоматического обхода целей символических ссылок и перехода на другие тома во время анализа или проверки содержимого.

## Дополнительная сложность и условия возврата

Потребуются хранение раскрытых ветвей, построение списка видимых строк, восстановление положения курсора при сворачивании и обработка исчезнувших папок. Во всех экранах нужно однозначно различать выделенную строку и корень анализа.

До реализации проверить сценарии: раскрытие не запускает `du`; раскрытие не меняет корень и отметки; `R` сбрасывает контекст анализа; вложенный объект нельзя отметить на удаление; маска вложенного имени действует на весь корень; исчезновение раскрытой папки не переносит выбор на другой объект; отмена и ошибки сохраняют понятное состояние интерфейса.

Вернуться к этому варианту стоит после использования MVP, если частые переходы мешают осматривать соседние ветви или настройка вложенных исключений вручную неудобна. Перед реализацией согласовать поведение курсора, сворачивания и перехода к родителю корня, а также отображение строк с неизвестным размером.

Кэш размеров посещённых каталогов и выбор объектов из нескольких уровней — отдельные возможные улучшения. Они не входят автоматически в этот вариант и требуют собственных правил актуальности и подтверждения.
